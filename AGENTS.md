# Diretrizes do projeto

- Use a skill Sonetro no código, documentação e explicações desta atividade.
- Trabalhe em português brasileiro, com mudanças pequenas e sem refatorações fora do escopo.
- Este projeto entrega somente backend. Não crie telas ou dependências de frontend.
- Use uma branch por feature; não implemente funcionalidades diretamente na main.
- Reaproveite os padrões e componentes do login-java antes de adicionar dependências.
- Valide o fluxo integrado quando a feature estiver disponível e registre somente verificações executadas.
- Não faça commit, push ou merge sem autorização do usuário.
